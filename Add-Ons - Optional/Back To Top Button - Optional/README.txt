Back to Top Button

INSTALL:
Upload the includes folder from this ZIP to your Zen Cart /ROOT/ directory,
merging folders (do not replace the whole includes folder).

File installed:
includes/templates/responsive_classic/jscript/jscript_ddk_back_to_top.php

Zen Cart automatically includes jscript_*.php template scripts.
No template edits or database changes needed.

The button appears after scrolling down 300px and smoothly scrolls to top.
